# Academic Website Template


A simple Quarto academic website template.

## Getting started

1.  Fork this repository
2.  Edit `_quarto.yml`
3.  Replace example content
4.  Run:

``` terminal
quarto render
```

### Tips

You can edit the website and see how the changes effects the website by
running:

``` terminal
quarto preview
```

To stop the preview running use “ctrl+c” in the terminal

## Enable GitHub Pages

1.  Open your repository on GitHub
2.  Go to:

``` text
Settings → Pages
```

3.  Under **Build and deployment**:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/docs**

4.  Click **Save**

## Wait for deployment

GitHub will build and publish your site.

This may take a few minutes the first time.

Your website will usually appear at:

``` text
https://YOUR-USERNAME.github.io/REPOSITORY-NAME/
```

Example:

``` text
https://drmattg.github.io/Academic_website_template/
```
